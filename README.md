Movie-Tutorial

Movie-Tutorial is a web application built with React, Vite, and JavaScript that fetches movie data from an external API and displays information about movies.


Technologies:

React – Frontend framework for building user interfaces

Vite – Fast development tool for React applications

JavaScript – Main programming language

Fetch API – For fetching data from the API

Features

✅ Fetches movie data from an API✅ Movie search functionality✅ Displays detailed movie information✅ Styled components
